# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, welcoming and constructive; harassment and discrimination are not tolerated.
Report concerns privately via a GitHub security advisory contact or by opening a minimal issue asking maintainers to reach out.
Maintainers may remove contributions or restrict participation that violate these standards.
